# 🔍 Data Digger — SQL Project Documentation

## Objective

"Data Digger" is a practical SQL project that provides hands-on experience in managing a MySQL database using CRUD operations, clauses, operators, aggregate functions, primary keys, and foreign keys. Students will design and manipulate a structured relational database for an E-Commerce Store to gain deeper insights into SQL query execution.

## About This Document

This README walks through **every SQL statement** in `data_digger.sql`, in the same order it appears in the file, explains what each statement does, and shows its **actual output**. All outputs below were generated by running the queries live through a Python script (`run_digger.py`, included in this project) so the tables you see are real query results, not hand-typed examples.

## Database Schema

The database `data_digger` contains four related tables:

| Table | Purpose | Key Relationships |
|---|---|---|
| `customer` | Stores customer details | Primary Key: `customer_id` |
| `orders` | Stores order headers | FK `customer_id` → `customer.customer_id` |
| `product` | Stores product catalog | Primary Key: `product_id` |
| `order_details` | Line items per order | FK `order_id` → `orders.order_id`, FK `product_id` → `product.product_id` |

```
customer (1) ───< orders (1) ───< order_details >─── (1) product
```

## 1. Customer Table

The `customer` table is created with `customer_id` as the **primary key**, and five sample customers are inserted with `INSERT INTO`.

```sql
CREATE TABLE customer(
```

## 2. Orders Table

### 2.1 Create & Populate

The `orders` table links back to `customer` via a **foreign key** on `customer_id`.

```sql
CREATE TABLE orders(
order_id INT PRIMARY KEY,
customer_id INT,
order_date DATE,
total_amount DECIMAL(10,2),
FOREIGN KEY (customer_id) REFERENCES customer(customer_id)
);

INSERT INTO orders(order_id, customer_id, order_date, total_amount)
VALUES
(101, 1, '2026-09-05', 150.50),
(102, 2, '2026-09-01', 85.00),
(103, 3, '2026-08-20', 200.00),
(104, 4, '2026-07-15', 45.25),
(105, 5, '2026-09-10', 310.00);
```

**All orders after insert:**

```sql
SELECT * FROM orders;
```

### 2.5 Date Filtering (`INTERVAL`)

Returns orders placed within the last 30 days from today's date. *(In MySQL this uses `CURRENT_DATE - INTERVAL '30' DAY`; the Python simulation uses SQLite's equivalent `date('now','-30 days')` to produce the same logic.)*

```sql
SELECT * FROM orders WHERE order_date >= CURRENT_DATE - INTERVAL '30' DAY;
```

**Output:**

|   order_id |   customer_id | order_date   |   total_amount |
|-----------:|--------------:|:-------------|---------------:|
|        101 |             1 | 2026-09-05   |          150.5 |
|        103 |             3 | 2026-08-20   |          200   |
|        105 |             5 | 2026-09-10   |          310   |

---

### 2.6 Aggregate Functions (`MAX`, `MIN`, `AVG`)

Computes the highest, lowest, and average order amount across all remaining orders.

```sql
SELECT MAX(total_amount) AS HighestAmount, MIN(total_amount) AS LowestAmount, AVG(total_amount) AS AverageAmount FROM orders;
```

**Output:**

|   HighestAmount |   LowestAmount |   AverageAmount |
|----------------:|---------------:|----------------:|
|             310 |          150.5 |          223.63 |

## 4. Order Details Table

### 4.1 Create & Populate

`order_details` is the junction table connecting `orders` and `product`, holding one row per line item.

```sql
CREATE TABLE order_details(
order_detail_id INT PRIMARY KEY,
order_id INT,
product_id INT,
quantity INT,
subtotal DECIMAL(10,2),
FOREIGN KEY (order_id) REFERENCES orders(order_id),
FOREIGN KEY (product_id) REFERENCES product(product_id)
);

INSERT INTO order_details(order_detail_id, order_id, product_id, quantity, subtotal)
VALUES
(1, 101, 1, 1, 450.00),
(2, 101, 4, 2, 1200.00),
(3, 103, 2, 1, 1800.00),
(4, 104, 4, 1, 600.00),
(5, 105, 5, 2, 2400.00);
```

**All order line items after insert:**

```sql
SELECT * FROM order_details;
```

### 4.4 Best-Selling Products (`GROUP BY` + `ORDER BY` + `LIMIT`)

Groups line items by product, sums quantity sold per product, and returns the top 3 best-sellers by quantity.

